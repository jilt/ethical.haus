Roadmap

A clearer path from signal capture to reward distribution, designed to feel more readable and less visually noisy.

  • Phase 1: Launch Postgres/Filecoin hybrid data layer and start Neynar agent testing.
  • Phase 2: Release multichain trading Mini App and mint ERC-8004 agent identity.
  • Phase 3: Full integration of multichain Creatorcoin/Buildercoin streaming rails and reward distribution.

Year 1 Target: ~$120k ARR driven by execution fees, API subscriptions, and community rewards.
